# Evaluador de Pádel FAP (Prototipo)

Aplicación web basada en el **Método Sistemático de Categorización** del Colegio de Fiscales de la Federación Argentina de Pádel (2010).

## Objetivo
Digitalizar el proceso de evaluación de jugadores de pádel para determinar su categoría (7ª a 1ª) según los criterios del manual oficial.

## Estado actual
- [x] Prototipo funcional: Par I del Smash (Golpe-Impacto)
- [ ] Par I' del Smash (Desplazamientos de posicionamiento)
- [ ] Par II y II' del Smash
- [ ] Volea, Pegada de Fondo, Salida de Pared
- [ ] Algoritmo de ponderación global
- [ ] PWA completa con almacenamiento local

## Cómo probarlo
1. Cloná el repositorio.
2. Abrí `index.html` en tu navegador.
3. Seleccioná las descripciones que coincidan con lo que observás en un jugador.
4. Hacé clic en "Obtener Diagnóstico".
